## Evidence handling note

The Eco One manual owns the exact one-liter recipe and its 40/60/100/200 ppm rows; the current official product page adds the 500 ppm/40-minute row. The separate EWCO technical page supplies one half-liter validation point: 500 mL at 200 ppm in 8 minutes. The developer preserves these anchors and applies no wattage correction because DC output current/watts are undisclosed. Electrochemical theory and controlled studies confirm that changing NaCl changes conductivity, current, current efficiency, and chlorine production. For the user-requested practical 0.60 g/L recipe, the tool estimates conductivity as concentration^0.95 and multiplies the 2.00 g/L time by 3.14. That factor is an explicit constant-voltage/constant-efficiency calibration scenario, not an Eco One measurement. The Amazon/Chloe recipe now uses the user-corrected approximate 250 mL / 300 ppm / 30-minute result as its first-class default rate point, assuming the review amounts were volume-scaled; its displayed time increases above 250 mL and decreases below 250 mL. The earlier 15-minute planner entry and original review claim remain historical source context. Its pH selector remains a measured-result target and vinegar stays at the locked 2.5 mL/L Amazon/Chloe ratio. None of these sources makes a salt-only or PWPAM manual compatible.
