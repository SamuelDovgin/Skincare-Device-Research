## Evidence handling note

The Eco One manual owns the exact one-liter recipe and its 40/60/100/200 ppm rows; the current official product page adds the 500 ppm/40-minute row. The developer preserves those one-liter anchors and labels all between-anchor interpolation and 500–950 mL time scaling as sensitivity estimates. Its pH selector is anchored to the two Stony Brook final-pH observations for the 5 mL/L recipe, capped at the manual source rate, and presented as illustrative rather than validated. The 100 ppm default is a cross-source concentration reference, not an “optimal” dose or evidence of home-batch product equivalence. None of these sources makes a salt-only or PWPAM manual compatible.
