# PWPAM Manual Boundary: Preserve the Record, Do Not Convert It Into a Vinegar Recipe

## What the supplied manual establishes

The received PWPAM photographs state that the device produces sodium hypochlorite disinfectant from water and salt. Its printed table uses discrete water/salt-scoop/time rows and a coarse 20–1,500 ppm chlorine strip scale. It also frames output use around cleaning, rinsing objects, ventilation, and keeping people/pets away after high-concentration spraying. [[1]](../19_diy_topical_formulation/source_docs/pwpam_manual_2026-08-24_recipe-and-use.jpg)[[2]](../19_diy_topical_formulation/source_docs/pwpam_manual_2026-08-24_test-strip-scale.jpg)[[3]](../19_diy_topical_formulation/source_docs/pwpam_manual_2026-08-24_warnings.jpg)

The manual does **not** document:

- adding vinegar or another acid;
- a final pH target or pH test method;
- an acidified-brine cycle;
- a cosmetic, facial, eye-area, or face-contact-bedding application;
- an independently adjustable scoop-mass recipe.

## The decision

This means the PWPAM belongs in a **salt-only manual-reproduction record**, not in the acidified-brine formula shown by this new topic. The old DIY topic retains its PWPAM record so the device’s actual instructions are not lost, but its visible navigation now sends pH-controlled HOCl work here first.

Using a kitchen scale for the salt is still useful only as a record: tare a dry compatible cup, weigh the exact number of supplied level scoops for a documented manual row, and repeat that same mass if the manual permits a repeat. The scale makes a manual row repeatable; it does not license a new salt concentration or an added acid.

## Why “after the run” is not safer

Adding vinegar after electrolysis is still mixing acid with a chlorine-containing solution. CDC warns that hypochlorites release toxic chlorine gas when mixed with acid or ammonia. The generic compatibility checker therefore blocks both “before” and “after” workarounds for PWPAM or any salt-only manual. [[4]](https://www.cdc.gov/infection-control/hcp/disinfection-sterilization/chemical-disinfectants.html)

## Where to go instead

- To verify a PWPAM manual row without altering it, use the existing [legacy PWPAM manual-check record](../19_diy_topical_formulation/hypochlorous_water_planner.html).
- To assess a **different** device whose manual explicitly permits acidified brine, use the [compatibility checker](product_compatibility_checker.html) and then the [HOCl recipe & output guide](hypochlorous_acid_calibration_planner.html).
- For a topical or facial goal, use a finished appropriately labeled product; neither PWPAM output nor this DIY calibration workflow is a substitute.
