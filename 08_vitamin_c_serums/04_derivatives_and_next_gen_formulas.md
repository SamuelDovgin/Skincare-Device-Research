# Vitamin C Derivatives & Next-Gen Formulas

*Compiled 2026-07-04. The phrase "better vitamin C" usually means more stable or more tolerable, not automatically more proven.*

## 0. Bottom line

The old SkinCeuticals question was:

> How do we get active L-ascorbic acid into skin without it falling apart?

The newer market question is:

> Can we get better stability, feel, and pigment results by using derivatives, water-free systems, encapsulation, or multi-pathway brightening formulas?

That second question is interesting, but it changes the evidence standard. A derivative serum can be a better daily product for a real person while still having less classic photoprotection evidence than C E Ferulic.

## 1. Derivative map

| Ingredient | Also called | Why brands like it | Main caveat |
|---|---|---|---|
| **Ascorbyl glucoside** | Vitamin Cg | More stable, water-compatible, gentler; L'Oreal/Kiehl's use it heavily | Must convert to active vitamin C; not the same as low-pH LAA delivery |
| **Tetrahexyldecyl ascorbate / ascorbyl tetraisopalmitate** | THD, ATIP | Oil-soluble, elegant, often well tolerated | Strong marketing, less direct classic photoprotection data |
| **3-O-ethyl ascorbic acid** | Ethyl ascorbic acid | More stable, water/oil miscibility claims, brightening focus | Patent origin is not L'Oreal; conversion/clinical potency varies |
| **Sodium ascorbyl phosphate** | SAP | Gentler, water-soluble, acne-friendly positioning | Lower pure vitamin C delivery confidence |
| **Magnesium ascorbyl phosphate** | MAP | Gentle, stable, common in creams | Older Duke absorption model did not show increased LAA skin levels |
| **Ascorbyl palmitate** | AP | Oil-soluble antioxidant support | Weak as standalone "vitamin C serum" logic |

## 2. L'Oreal/Kiehl's: Vitamin Cg + water-free LAA

Kiehl's Powerful-Strength Vitamin C Serum is a useful L'Oreal-group example because it is not a C E Ferulic clone. It uses:

- **10.5% L-ascorbic acid**
- **2% Vitamin Cg / ascorbyl glucoside**
- fragmented hyaluronic acid
- a **water-free** concentrate

Kiehl's says pure vitamin C starts working immediately while Vitamin Cg activates after absorption into upper skin layers to support longer-term vitamin C activity.

Practical read:

- likely better feel/tolerance than watery low-pH CEF clones for some people;
- not the same antioxidant system as C E Ferulic;
- good "daily compliance" option if CEF-style products are too stingy or smelly.

## 3. L'Oreal Paris: Melasyl + Vitamin Cg + niacinamide

L'Oreal Paris UK is now positioning Revitalift Triple Laser Creamy-Serum around:

- **Melasyl** (INCI: 2-mercaptonicotinoyl glycine), described by L'Oreal as a patented active;
- **Vitamin Cg** / ascorbyl glucoside;
- **niacinamide**;
- support actives such as LHA/HEPES, glycerin, and licorice-root derivative.

This is not "new vitamin C beats C E Ferulic." It is a different strategy:

| C E Ferulic | L'Oreal Melasyl + Cg + niacinamide |
|---|---|
| Antioxidant photoprotection benchmark | Cosmetic dark-spot/brightening system |
| Pure low-pH LAA | Vitamin C derivative |
| Strong C/E/ferulic literature | Newer L'Oreal pigment-pathway active claims |
| Best read: environmental antioxidant | Best read: accessible dark-spot cosmetic |

For pigment-prone skin, this type of multi-pathway formula may be more relevant than vitamin C alone, especially if it is less irritating.

## 4. THD / ascorbyl tetraisopalmitate

THD and ascorbyl tetraisopalmitate are oil-soluble vitamin C derivatives. They are popular in modern prestige formulas because they are easier to make elegant and stable than low-pH LAA.

Patent signal:

- L'Oreal-owned **US10231911B2** includes high-percentage ascorbyl tetraisopalmitate in targeted booster compositions for brightness and pore visibility.

Practical read:

- good for users who cannot tolerate low pH;
- often pairs well with retinoid routines because it can be less stingy;
- do not assume "30% THD" equals "30% LAA" biologically.

## 5. 3-O-ethyl ascorbic acid

3-O-ethyl ascorbic acid is a stabilized derivative with whitening/brightening patent literature. **US7741496B2** from Corum describes 3-O-ethyl-ascorbic acid as a structurally stable ascorbic acid derivative and whitening agent.

Practical read:

- interesting for brightening;
- often nicer than low-pH LAA;
- not a direct SkinCeuticals successor and not specifically a L'Oreal invention in the patent source checked.

## 6. What "supposedly works better" should mean

Better can mean four different things:

| Meaning of better | Example | How to judge |
|---|---|---|
| Better skin delivery | Low-pH LAA | pH, concentration, absorption data |
| Better stability | Vitamin Cg, THD, water-free systems | potency after months, packaging, color/assay |
| Better tolerability | derivatives, lower LAA | less sting, better barrier, easier daily use |
| Better pigment strategy | Melasyl + niacinamide + Cg | multi-pathway clinical pigment data |

For a real routine, tolerability can beat theoretical potency. A perfect 15% LAA serum that irritates you into PIH is worse than a gentler derivative you can use consistently.

## 7. What I would watch next

| Watch item | Why it matters |
|---|---|
| SkinCeuticals' promised/rumored 2026 patent-pending antioxidant formula | Could show how the brand plans to replace the expired CEF patent moat |
| More post-patent CEF clones | Trader Joe's is likely only the beginning |
| Airless/oxygen-limiting packaging | May matter more than tiny ingredient tweaks |
| Independent vitamin C assay testing | The best way to separate real dupes from label copies |
| Melasyl long-term independent data | L'Oreal's pigment claims are interesting and current |
| Derivative head-to-heads against LAA | Still the missing evidence for many "newer vitamin C" claims |

## 8. User-specific take

Since Differin is already in the routine:

- choose classic CEF-style LAA if skin is calm and you want antioxidant photoprotection;
- choose Vitamin Cg/THD/ethyl ascorbic acid if low pH stings or causes redness;
- choose Melasyl/niacinamide/Cg-style products if dark spots are the main target and you want a lower-irritation cosmetic brightener;
- keep sunscreen as the anchor no matter which vitamin C path you choose.
