# Vitamin C Serum Quick Selection Guide

*Pick the right vitamin C serum for your skin, budget, and routine in 60 seconds. For full details and evidence, see the numbered docs this references.*

---

## Step 1: What's your main goal?

| Goal | Best vitamin C form | Jump to |
|---|---|---|
| **Maximum antioxidant photoprotection** (proven evidence) | Pure L-ascorbic acid, low pH | §A |
| **Brightening / dark spots / PIH** (pigment focus) | LAA or multi-pathway pigment system | §B |
| **Anti-aging / collagen maintenance** (texture, fine lines) | LAA or THD ascorbate | §A or §C |
| **Gentle daily use with Differin/retinoid** (no sting) | THD ascorbate or ascorbyl glucoside | §C |
| **Acne-prone, very sensitive** (zero irritation) | Sodium ascorbyl phosphate (SAP) | §D |
| **Cheapest possible that actually works** | Budget LAA or DIY | §E |

## The 30-Second Picker

Answer these three questions:

**1. Does low-pH L-ascorbic acid sting your face?**
- No → Go §A (LAA serums)
- Yes / I use Differin → Go §C (THD) or CeraVe 10% (§A)

**2. What's your budget?**
- Under $30 → Go §E
- $30–$80 → Paula's Choice C15 (§A) or Medik8 C-Tetra (§C) or INNBEAUTY (§B)
- Over $80 → SkinCeuticals C E Ferulic (§A) or Sunday Riley C.E.O. (§C)

**3. What's your main goal?**
- Photoprotection / anti-aging → §A
- Dark spots / PIH → §B
- Zero irritation → §C or §D

## Quick Routine Rules

| Rule | Why |
|---|---|
| **Vitamin C in the AM, Differin/retinoid in the PM** | Separates acid from retinoid = less irritation |
| **Sunscreen every morning, no exceptions** | Vitamin C boosts photoprotection, doesn't replace SPF |
| **If it turns orange/brown, discard it** | Oxidized vitamin C is useless and potentially irritating |
| **Airless pump > tube > dropper** | Less air exposure = longer potency |
| **Store in fridge if possible** | Slows oxidation |
| **Start 3-4x/week, not every day** | Build tolerance especially if using Differin |
